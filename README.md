# OPPORTUNITY LIVE

**Find what's next. Before everyone else.**

A global opportunity discovery platform for internships, scholarships, hackathons, grants, jobs, fellowships and more.

## Design

Premium dark theme inspired by modern SaaS products (Linear, Stripe, Vercel aesthetic — original implementation).

- Near-black background
- Electric green accent
- Glass cards, thin borders, large typography

## Tech Stack

- Next.js 16 (App Router)
- TypeScript
- Tailwind CSS v4
- Demo seed data (clearly labeled)

## Pages

- `/` — Landing with live opportunity feed
- `/discover` — Explore + filters
- `/opportunity/[slug]` — Detail page with source transparency
- `/radar` — Personalized opportunity radar

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Demo Data

All opportunities currently use **DEMO DATA**. Real ingestion pipeline architecture is prepared for future connection to PostgreSQL + workers.

## Deployment

Compatible with Vercel / Netlify.
